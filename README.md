# Desarrollo de aplicaciones móviles para Sistemas Operativos IOS Nivel Avanzado

## Plataforma de laboratorios

Te damos la bienvenida a la plataforma de laboratorios del curso Desarrollo de aplicaciones móviles para Sistemas Operativos IOS Nivel Avanzado.

Mediante prácticas incrementales, desarrollarás CampusExplorer aplicando arquitecturas modulares, inyección de dependencias, programación reactiva, concurrencia, mapas y ubicación. También incorporarás pruebas automatizadas, integración continua y organización de componentes mediante VIPER.

Cada laboratorio continúa el trabajo del capítulo anterior. Revisa los prerrequisitos de cada guía antes de comenzar.

## Lista de laboratorios

Haz clic en los enlaces para consultar las instrucciones de cada práctica.

### Capítulo 1: Arquitecturas Modulares y DI (en, Kotlin Multiplataforma, Xcode y Swift)

#### [Práctica incremental](Capitulo01/README.md)

- Descripción: Crear la línea base de CampusExplorer aplicando arquitectura MVVM, Coordinator Pattern, modularización con Swift Package Manager e inyección de dependencias.
- ⏱️ Duración estimada: 216 min (3 h 36 min).

### Capítulo 2: Programación Reactiva con Combine

#### [Práctica incremental](Capitulo02/README.md)

- Descripción: Consumir una API HTTP con URLSession.DataTaskPublisher y aplicar operadores de Combine, networking reactivo y gestión de estado para implementar una búsqueda con espera, deduplicación y cancelación.
- ⏱️ Duración estimada: 252 min (4 h 12 min).

### Capítulo 3: Concurrencia Avanzada y Performance (en, Kotlin Multiplataforma, Xcode y Swift)

#### [Práctica incremental](Capitulo03/README.md)

- Descripción: Migrar la carga de datos a async/await, aplicar concurrencia estructurada y utilizar el actor CampusCache. Ejecutar operaciones costosas fuera del hilo principal y documentar las mejoras con Instruments.
- ⏱️ Duración estimada: 288 min (4 h 48 min).

### Capítulo 4: Frameworks

#### [Práctica incremental](Capitulo04/README.md)

- Descripción: Mostrar lugares del campus mediante MapKit, gestionar permisos y distancias con Core Location y encapsular la funcionalidad de ubicación en el framework local CampusLocationKit.
- ⏱️ Duración estimada: 252 min (4 h 12 min).

### Capítulo 5: Testing Avanzado y CI

#### [Práctica incremental](Capitulo05/README.md)

- Descripción: Probar ViewModels y flujos de Combine con XCTestExpectation, incorporar pruebas de snapshot y configurar la integración continua mediante GitHub Actions.
- ⏱️ Duración estimada: 252 min (4 h 12 min).

### Capítulo 6: Modularización y VIPER

#### [Práctica Extra](Capitulo06/README.md)

- Descripción: Refactorizar una lista y un detalle de tareas hacia módulos VIPER con View, Interactor, Presenter, Entity, Router y Builder. Organizar el flujo de datos, las dependencias y la navegación mediante coordinators.
- ⏱️ Duración estimada: 180 min (3 h).
