# Desarrollo de aplicaciones móviles para Sistemas Operativos IOS Nivel Avanzado

El alumno aprenderá a desarrollar aplicaciones utilizando una variedad de frameworks de alta demanda en el mercado mediante el uso de storyboard, permitiendo la comunicación entre ellos mediante los segues y haciendo uso de buenas prácticas de la programación utilizando Git y GitHub, también aprenderán a utilizar inteligencia artificial.

También se exponen diferentes frameworks como son MapKit y Core Location permitiendo desarrollar aplicaciones que aprovechen las funcionalidades de ubicación y mapas como lo hacen las populares aplicaciones actuales Uber, Google maps, etc. Otro framework a abordar es Core Data el cual nos permite el modelado y la persistencia de datos.

Por último, el alumno conocerá los elementos necesarios para la configuración y publicación de una app en la App Store.
